# 商户后台与服务器图片

## 页面与权限

后台入口为 `/admin`。商家登录后进入自己商户的品牌设置；超级管理员先在商户管理中选择目标商户，再维护品牌、价格、盒型与报价预览。

数量阶梯配置数量、元/平方米和最低消费；工艺表配置名称、按面积或按数量计费、开机费和变量单价。修改后保存到商户配置。

## Logo 上传和发布

前端以 multipart/form-data 向 `POST /api/v1/merchant/:slug/logo` 上传，字段名为 `logo`，请求携带 Bearer 登录令牌。允许 PNG、JPEG、WebP、GIF，最大 256 KiB。接口必须验证登录者为当前商户或超级管理员，检查文件内容类型。

文件保存在服务器上传目录下，以随机文件名区分版本；接口返回 `logoUrl`。上传后先预览，保存品牌配置才发布该 URL。旧文件不自动删除，以免破坏已发布或历史配置引用。

前端和 API 不同域名/端口时，`/uploads/...` 图片地址须相对 API 所在站点解析。生产反向代理需转发 `/api/v1` 与 `/uploads`。部署时持久化上传目录；更新应用不能覆盖上传文件，备份数据库的同时备份上传目录。

上传目录已加入 `.gitignore`。服务器必须对上传目录具有写权限；不要通过源码仓库分发客户上传文件。

## 前台联系下单

商家维护微信号、微信二维码地址、QQ号和QQ联系链接。客户下单时重新获取服务端报价，再复制完整规格和金额摘要，随后展示联系入口。微信二维码用于扫码联系；QQ链接由客户点击打开。普通微信号不保证能直接打开聊天。

若浏览器拒绝剪贴板权限，应展示可手动复制的文本；未配置联系入口时提示客户，不打开空白链接。不通过此流程创建后端订单。
